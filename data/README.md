# Data and model inputs

This repository contains source code. Download the cited public datasets and stage the corresponding prepared tables and frozen model artifacts before running an analysis. The primary sources and assay interpretation are described in the manuscript and Document S1. Do not replace supplied frozen artifacts with a new training run when comparing the manuscript's reported scores.

## HCT116 source inputs

Under `data/raw`, the retained training schemas use:

- `875_Compounds_Average_Data.csv`: protein rows with gene and UniProt annotation columns, followed by compound-average log2 fold changes.
- `1752_Experiments_Data_With_Replicate_for_VAE.csv`: replicate rows, `Sample_ID`, and ordered protein columns.
- `1628_Experiments_Data.csv`: original replicate-header reference used to distinguish measured and constructed pairs.
- `drug_hct116_classification_including_marginal_with_cluster.csv`: compound/sample identifiers, modeling labels and cluster annotations.
- `Uniprot_ID_to_Gene_name_mapping.csv` and `875_Drugs_Metainformation_ATC_Classfication.xlsx`: protein mapping and pharmacological annotations used by attribution/prioritization workflows.

Supply `c2.cp.v6.2.symbols.gmt` and `c6.all.v6.2.symbols.gmt` under `data/pathways/gmt_cache`; the clinical workflow also uses Hallmark GMT data. Some secondary analyses need their cached public annotations and prepared comparison tables.

## Frozen deployment artifacts

For each branch under `results/average` and `results/supcon`, supply the saved `branch_pca.pkl`, `branch_model_bank_summary.csv`, `branch_ensemble_node_labels.csv` and `branch_consensus_embedding_including_marginal.csv`, using `average` or `supcon` in place of `branch`. The raw UniProt attribution tables, enrichment matrices and classifier summaries are additional inputs for pathway and candidate analyses. These deployment files are retained study artifacts, not generated by a mere renaming of a different model's outputs.

Frozen HepG2 inference expects the Average original-recipe checkpoints under `results/drug_repurposing/models/average_replayed` and SupCon checkpoints under `results/source_model_checkpoints/supcon`. Each bank has 600 `.pt` files. Checkpoint hash manifests are read from `results/drug_repurposing/results`. Saved `RealTabPFN-v2.5` classifiers are read from `results/autogluon_protargetminer_four_spaces/predictors/{average_latent,supcon_latent}`. The PCA, membership and classifier schemas are checked before inference.

Copy the 17-profile processed input from the Zenodo release into `data/raw/hepg2_compounds_log2fc.csv`, and copy `MI-773_log2FC.csv` into `data/raw` without duplicating it. These staging names do not change the public release or its original checksums.

## Other analyses

- External preparation scripts document their public supplement or archive URLs and expected workbook schemas. Their derived data are stored in `results/external/{mcf7,jurkat,lung_cell_lines}` or the respective prepared external-data directory.
- CCK8 fitting uses `data/raw/cck_dose_response.xlsx`; the additional JP1302 workbook is `data/raw/cck_jp1302.xlsx`. Workbook layouts and source blocks are specified in the fitting implementation.
- Clinical processed supplements are placed in `data/clinical`; `scripts/clinical_analysis/download_processed_inputs.py` can retrieve public files. If a site presents an access challenge, download the published supplement manually. The R analysis also requires the HCT116 and A549 prepared matrices declared near its beginning.
- Disease reversal uses the prepared CPTAC and candidate-evidence inputs in `data/cptac` and `data/repurposing`. `encode_disease_profiles.py` writes intermediate encodings under `results/drug_repurposing`; its standalone R companions consume those encodings and supplied PRISM evidence tables.
- Matched pathway-comparison intermediates are stored in `results/pathway_comparison/data`; exact source-model comparisons require the supplied branch and comparator attribution matrices.

The source repository does not contain vendor raw mass-spectrometry data, patient-level restricted material, trained model banks or predictor weights. No such missing asset is substituted with simulated data.
